1、CreateFileW函数

创建或打开文件或I/O设备（文件、文件流、目录、物理磁盘、卷、控制台缓冲区、磁带驱动器、通信资源、mailslot和管道）。它会返回一个句柄，可用于访问各个类型的I/O文件或设备，具体取决于文件或设备以及指定的标志属性。

语法：

LPCWSTR（Long Pointer to Constant Wide String）指向常量宽字符串的长指针 实际类型：const wchar_t* 。 用途：指向Unicode（UTF-16）字符串的只读指针

DWORD（Double Word）双字（32位无符号整数） 实际类型：unsigned long 。 用途：存储各种标志和模式值

LPSECURITY_ATTRIBUTES（Long Pointer to SECURITIY_ATTRIBUTES）指向安全属性结构的长指针 实际类型：struct _SECURITY_ATTRIBUTES*。 用途：指定文件的安全性和继承性

HANDLE（Handle）句柄（INVALID_HANDLE_VALUE表示无效句柄）是个标识符 实际类型：void* 。 用途：引用系统资源（文件、进程、线程等）

常用参数：

[ in ] dwDesiredAccess GENERIC_READ（只读访问）、GENERIC_WRITE（只写访问）、GENERIC_READ|GENERIC_WRITE（同时具有读写权限）

[ in ] dwShareMode（控制其他进程如何访问同一文件） FILE_SHARE_READ（允许其他进程读取该文件）、FILE_SHARE_WRITE（..写入..）、FILE_SHARE_DELETE（..删除..）

[in, optional] lpSecurityAttributes：指向包含两个独立但相关数据成员的 SECURITY_ATTRIBUTES 结构的指针：可选的安全描述符，以及一个布尔值，该值确定是否可由子进程继承返回的句柄。

此参数可以 NULL。

如果此参数 NULL，则应用程序可能创建的任何子进程都无法继承由 CreateFile 返回的句柄，并且与返回的句柄关联的文件或设备将获取默认的安全描述符。

[ in ] dwCreationDisposition（对文件或设备执行操作）（对于文件以外的设备参数设置为OPEN_EXISTING） 此参数的值为：（不能组合） CREATE_ALWAYS：创造新文件

CREATE_NEW：该文件不存在时才会创建新文件

OPEN_ALWAYS：打开文件

OPEN_EXISTING：文件或设备存在才打开，若不存在函数失败

TRUNCAT_EXISTING：文件存在时，打开一个文件并截断它，让它大小为零字节

[ in ] dwFlagsAndAttributes（文件或设备属性和标志） FILE_ATTRIBUTE_NORMAL是文件最常见的默认值

[in, optional] hTemplateFile（具有GENRIC_READ访问权限的模板文件的有效句柄）

打开现有文件时，CreateFile忽略此参数。

返回值：

函数成功返回值是：指定文件、设备、命名管道或邮件槽的打开句柄

函数失败返回值为：INVALID_HANDLE_VALUE

使用 CreateFile返回的对象句柄完成应用程序后，请使用 CloseHandle 函数关闭句柄。

2、ReadFile函数

从指定文件或设备读取数据，此函数用于同步操作和异步操作。

如果设备支持，则读取发生在文件指针指定的位置。（古书中有记载）

语法：

参数：
[ in ] hFile

若异步操作中FILE_FLAG_OVERLAPPED 标志打开的任何句柄

[ out ] lpBuffer（指向接收从文件或设备读取的缓冲区的指针）

[ in ] nNumberOfBytesToRead（要读取的最大字节数）

[ out, optional ] lpNumberOfBytesRead（指向同步hFile参数接收读取的字节数的变量的指针）

ReadFile在执行工作或检查错误要将这个值设置为0，若为异步操作用NULL

[ in, out, optional ] lpOverlapped（用于支持异步I/O操作的关键结构体指针）

若使用了异步操作中FILE_FLAG_OVERLAPPED打开hFile参数则需要指向OVERLAPPED结构指针，否则可以为NULL 重叠结构（minwinbase.h）包含用于异步 (或 重叠) 输入和输出 (I/O) 的信息

返回值：

函数成功返回值是：非零

3、WriteFile函数

将数据写入指定的文件或输入/输出（I/O）设备。（WriteFileEx严格采用异步模式，WriteFile默认同步）

语法：

参数与返回值与ReadFile一样

4、CloseHandle(HANDLE hObject)函数

关闭打开的对象句柄。

语法：

参数：

[ in ] hObject

打开对象的有效句柄

返回值：

成功：非零

失败：为零

5、GetFileSizeEx函数

检索指定文件的大小。(windows应用商店应用不支持)

语法：

参数：

[ out ] lpFileSize（指向接收文件大小，以字节为单位）

指向LARGE_INTEGER结构的指针

返回值：

成功：非零

失败：为零

6、GetFileAttributesW函数

检索指定文件或目录的文件系统属性。

语法：

参数：

[ in ] lpFileName（文件/目录的名称）

名称限制为MAX_PATH个字符

返回值：

成功：包含指定文件或目录的属性

失败：返回值INVALID_FILE_ATTRIBUTES

7、 CreateDirectoryW函数

创建新目录

语法：

参数：

[ in ] lpPathName（要创建的目录的路径）

名称限制为MAX_PATH个字符

[ in ,optional ] lpSecurityAttributes

指向SECURITY_ATTRIBUTES结构的指针

（SECURITY_ATTRIBUTES是 Windows API 定义的结构体，核心作用是 为内核对象（如文件、进程、线程、管道、互斥体等）配置「安全访问规则」和「句柄继承性」。）

如果 lpSecurityAttributesNULL，则目录将获取默认的安全描述符

返回值：

成功：非0

失败：为0，若要获取扩展错误信息，调用GetLastError
